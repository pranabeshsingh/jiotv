When do you need a proxy?
• Direct Mode (Default): If this server is hosted on a home PC, Raspberry Pi, or residential ISP, leave the proxy OFF. Jio connects directly.
• Proxy Mode: Jio's Fastly CDN blocks cloud datacenters (Oracle Cloud, AWS, DigitalOcean) with HTTP 450 for channel catalogs. If running in a cloud VM, enable this toggle and point to your residential proxy (e.g. over Tailscale).

Kodi PVR IPTV Simple Client Setup

1
Install Addon: In Kodi, navigate to Settings ➔ Add-ons ➔ Install from repository ➔ PVR clients ➔ PVR IPTV Simple Client and click Install.
2
Configure M3U Playlist: Open Add-on Settings ➔ General ➔ M3U Play List URL, paste your Working Playlist URL: {{ base_url }}/playlist_working.m3u.
3
Configure EPG Guide: In Add-on Settings ➔ EPG ➔ XMLTV URL, paste: {{ base_url }}/epg.xml.gz.
4
Enable InputStream Adaptive: Navigate to Settings ➔ Add-ons ➔ VideoPlayer InputStream ➔ InputStream Adaptive and ensure it is Enabled for hardware DRM video decoding.
